# Cursor Rules

This directory contains rules and instructions for AI agents working on this codebase.

## Available Rules

- [Design Tokens](./design-tokens.md) - Guidelines for using the centralized design system and style tokens
- [Testing](./testing.md) - Best practices for writing tests with Jest and React Testing Library
- [React/TypeScript/React Native](./react-typescript-react-native.md) - Best practices for React, TypeScript, and React Native development

## How to Use

These rules are automatically loaded by Cursor to guide AI assistance. They ensure consistency and best practices across the codebase.

## Quick Reference

| Rule | When to Use |
|------|-------------|
| Design Tokens | When styling components - use tokens instead of hardcoded values |
| Testing | When writing or modifying tests for components and utilities |
| React/TypeScript/React Native | When writing component logic, hooks, or TypeScript code |

## Adding New Rules

When adding new rules:
1. Create a new `.md` file in this directory
2. Use clear, actionable instructions
3. Include examples of correct and incorrect usage
4. Reference relevant documentation in `doc/` when applicable
