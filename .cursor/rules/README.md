# Cursor Rules

This directory contains rules and instructions for AI agents working on this codebase.

## Available Rules

- [Design Tokens](./design-tokens.md) - Guidelines for using the centralized design system and style tokens

## How to Use

These rules are automatically loaded by Cursor to guide AI assistance. They ensure consistency and best practices across the codebase.

## Adding New Rules

When adding new rules:
1. Create a new `.md` file in this directory
2. Use clear, actionable instructions
3. Include examples of correct and incorrect usage
4. Reference relevant documentation in `doc/` when applicable
