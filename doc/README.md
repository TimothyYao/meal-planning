### User Stories

User stories are organized by feature category:

- [Core Tracking & Logging](./user-stories/core-tracking.md) - Daily macro tracking, food database, barcode scanning, meal creation, quick logging
- [Meal Planning](./user-stories/meal-planning.md) - Weekly planning, meal prep, recipes, smart suggestions
- [User Profile & Goals](./user-stories/profile-goals.md) - Profile setup, macro calculations, progress tracking
- [Analytics & Insights](./user-stories/analytics.md) - Daily summaries, reports, distribution analysis
- [Shopping & Preparation](./user-stories/shopping.md) - Shopping lists, grocery integrations
- [Social & Sharing](./user-stories/social.md) - Sharing meal plans, community challenges
- [Advanced Features](./user-stories/advanced.md) - Intermittent fasting, macro cycling, integrations
- [Mobile-Specific](./user-stories/mobile-specific.md) - Offline mode, widgets, notifications
- [Web-Specific](./user-stories/web-specific.md) - Advanced analytics, bulk planning
