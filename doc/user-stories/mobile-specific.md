# User Stories: Mobile-Specific Features

## US-025: Offline Mode

**As a** mobile user  
**I want to** use the app offline  
**So that** I can log meals even without internet

**Acceptance Criteria:**
- Cache food database locally
- Log meals offline
- Sync when connection restored
- Indicate offline status

---

## US-026: Widget Support

**As a** mobile user  
**I want to** see my macro progress on a widget  
**So that** I can check status without opening the app

**Acceptance Criteria:**
- Home screen widget
- Show current macro progress
- Quick log button
- Customizable widget size

---

## US-027: Notifications & Reminders

**As a** user  
**I want to** receive reminders to log meals  
**So that** I don't forget to track my nutrition

**Acceptance Criteria:**
- Meal logging reminders
- Goal progress notifications
- Weekly summary notifications
- Customizable notification schedule
