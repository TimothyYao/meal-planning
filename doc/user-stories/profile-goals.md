# User Stories: User Profile & Goals

## US-010: Profile Setup

**As a** new user  
**I want to** set up my profile with goals and preferences  
**So that** the app can personalize my experience

**Acceptance Criteria:**
- Enter basic info (age, height, weight, activity level)
- Set fitness goal (lose/maintain/gain weight)
- Calculate recommended macro targets
- Customize macro targets manually

---

## US-011: Macro Target Calculation

**As a** user  
**I want to** have my macro targets calculated automatically  
**So that** I know how much to eat to reach my goals

**Acceptance Criteria:**
- Use TDEE (Total Daily Energy Expenditure) calculation
- Adjust for goal (deficit/surplus for weight change)
- Support different macro splits (high protein, keto, etc.)
- Allow manual override

---

## US-012: Goal Progress Tracking

**As a** user  
**I want to** track my progress toward my goals  
**So that** I can see if my nutrition plan is working

**Acceptance Criteria:**
- Log weight and body measurements
- View progress charts over time
- See correlation between macros and weight changes
- Set and track milestone goals
