# User Stories: Core Tracking & Logging

## US-001: Daily Macro Tracking

**As a** user  
**I want to** log my meals and see my daily macro progress  
**So that** I can stay within my target macros

**Acceptance Criteria:**
- View daily macro targets (calories, protein, carbs, fat)
- Log meals with food items and quantities
- See real-time progress toward daily targets
- Visual indicators (progress bars, colors) for macro status

---

## US-002: Food Database Search

**As a** user  
**I want to** search for foods in a database  
**So that** I can quickly find and log foods I eat

**Acceptance Criteria:**
- Search by food name or brand
- Filter by category (fruits, proteins, etc.)
- View macro information per serving
- Add custom foods to personal database

---

## US-003: Barcode Scanning

**As a** user  
**I want to** scan barcodes to quickly add packaged foods  
**So that** I can log meals faster without manual entry

**Acceptance Criteria:**
- Scan barcode using device camera
- Auto-populate food information from database
- Handle cases where barcode is not found
- Allow manual override/correction

---

## US-004: Meal Creation

**As a** user  
**I want to** create meals with multiple food items  
**So that** I can log complete meals at once

**Acceptance Criteria:**
- Add multiple foods to a meal
- Adjust quantities for each food
- Name and save meals for reuse
- See total macros for the meal

---

## US-005: Quick Logging

**As a** user  
**I want to** quickly log common meals or foods  
**So that** I can track my nutrition without spending too much time

**Acceptance Criteria:**
- Access frequently logged foods/meals
- One-tap logging for favorites
- Recent meals quick access
- Voice input for hands-free logging
