# User Stories: Analytics & Insights

## US-013: Daily Summary

**As a** user  
**I want to** see a summary of my daily nutrition  
**So that** I can understand how well I met my targets

**Acceptance Criteria:**
- View total macros consumed vs. targets
- See breakdown by meal
- Identify which macros were over/under
- Get suggestions for next day

---

## US-014: Weekly/Monthly Reports

**As a** user  
**I want to** view weekly and monthly nutrition reports  
**So that** I can identify patterns and trends

**Acceptance Criteria:**
- Average daily macros over period
- Consistency metrics
- Trend charts for weight and macros
- Export reports as PDF

---

## US-015: Macro Distribution Analysis

**As a** user  
**I want to** see how my macros are distributed throughout the day  
**So that** I can optimize meal timing

**Acceptance Criteria:**
- Timeline view of meals and macros
- Identify gaps or heavy periods
- Suggest meal timing improvements
- Compare to optimal distribution patterns
