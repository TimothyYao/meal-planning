# User Stories: Shopping & Preparation

## US-016: Shopping List Generation

**As a** user  
**I want to** generate shopping lists from my meal plans  
**So that** I can shop efficiently

**Acceptance Criteria:**
- Auto-generate list from planned meals
- Group items by category
- Show quantities needed
- Check off items as purchased

---

## US-017: Grocery Store Integration

**As a** user  
**I want to** integrate with grocery delivery services  
**So that** I can order ingredients directly

**Acceptance Criteria:**
- Connect to Instacart, Amazon Fresh, etc.
- Add items to cart automatically
- Compare prices across stores
- Schedule delivery
