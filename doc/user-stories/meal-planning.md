# User Stories: Meal Planning

## US-006: Weekly Meal Planning

**As a** user  
**I want to** plan my meals for the week ahead  
**So that** I can prepare and shop accordingly

**Acceptance Criteria:**
- View weekly calendar view
- Plan meals for specific days
- See weekly macro distribution
- Copy meals between days

---

## US-007: Meal Prep Planning

**As a** user  
**I want to** plan meal prep sessions  
**So that** I can batch cook and save time

**Acceptance Criteria:**
- Create meal prep recipes
- Scale recipes for multiple servings
- Generate shopping lists from meal plans
- Track meal prep containers

---

## US-008: Recipe Management

**As a** user  
**I want to** save and manage my favorite recipes  
**So that** I can reuse them in meal plans

**Acceptance Criteria:**
- Create custom recipes with ingredients
- Calculate macros for entire recipe
- Scale recipes by servings
- Organize recipes into categories

---

## US-009: Smart Meal Suggestions

**As a** user  
**I want to** receive meal suggestions based on my goals  
**So that** I can discover new options that fit my macros

**Acceptance Criteria:**
- AI-powered meal recommendations
- Filter by dietary preferences (vegan, keto, etc.)
- Consider remaining daily macros
- Suggest meals that balance macros
