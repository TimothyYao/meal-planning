# User Stories: Advanced Features

## US-020: Intermittent Fasting Support

**As a** user following IF  
**I want to** track my eating windows  
**So that** I can plan meals within my fasting schedule

**Acceptance Criteria:**
- Set fasting/eating windows
- Visual timeline of eating periods
- Adjust meal timing suggestions
- Track fasting duration

---

## US-021: Macro Cycling

**As a** user  
**I want to** cycle my macros (e.g., carb cycling)  
**So that** I can follow advanced nutrition strategies

**Acceptance Criteria:**
- Set different macro targets per day
- Plan high/low carb days
- Visualize weekly macro patterns
- Auto-adjust meal suggestions

---

## US-022: Restaurant Menu Integration

**As a** user  
**I want to** see macros for restaurant menu items  
**So that** I can make informed choices when dining out

**Acceptance Criteria:**
- Search restaurant menus
- View macro information for items
- Log restaurant meals easily
- Save favorite restaurant meals

---

## US-023: Nutritionist Integration

**As a** user  
**I want to** share my data with a nutritionist  
**So that** I can get professional guidance

**Acceptance Criteria:**
- Grant access to nutritionist
- Share logs and progress reports
- Receive meal plan recommendations
- Message with nutritionist

---

## US-024: Fitness Tracker Integration

**As a** user  
**I want to** sync with my fitness tracker  
**So that** my calorie targets adjust based on activity

**Acceptance Criteria:**
- Connect to Apple Health, Google Fit, Fitbit
- Import activity data
- Adjust daily targets based on calories burned
- View activity vs. nutrition balance
